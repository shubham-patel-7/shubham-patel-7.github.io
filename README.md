# Personal Profile Webpage

Built with HTML and CSS, hosted on GitHub Pages.

## Files
- `index.html` - page structure and content
- `style.css` - colours, fonts, layout, responsive rules
- `profile.jpg` - profile photograph


## Publish on GitHub Pages
1. Create a **public** repository named `shubham-patel-7.github.io`, tick "Add a README file".
2. Click **Add file > Upload files**, drag in `index.html`, `style.css` and your photo, then **Commit changes**.
3. Go to **Settings > Pages**, choose **Deploy from a branch**, branch `main` / `(root)`, click **Save**.
4. Wait about a minute (green tick under the Actions tab), then open `https://shubham-patel-7.github.io`.
5. Submit that URL.
